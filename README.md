A tiny Node 22 program (standard library only, no network) that writes one short text to `/output/entry.txt` — a quiet evening scene written to relax the AI judge reading it: a kettle gone quiet, light leaving the roofs, a cat asleep with a paw over its eyes, tea still warm.

Run it with:

```sh
node main.ts
```
